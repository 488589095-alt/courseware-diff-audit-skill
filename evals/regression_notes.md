用 `第9讲-英语`、`古诗` 两个 case 做回归——它们都有用户手工对比结论作真值。
要求自动审计在**机械事实层**复现手工结论（A/B/C 归因仍由 Claude 在报告环节完成）。

跑法（任一 case）：
```bash
python3 scripts/run_audit.py --case output/handout-to-courseware/<case> --no-screenshots
```

## 结论
- 机械事实层**复现两份手工结论**：英语「内容全转入 + 5 类老师增量」、古诗「A 类全 hit + 知识精讲/解析按贴标杆忽略」。
- **边界测试通过**：古诗「讲义有+标杆无」的解析类内容，脚本不擅判 bug，留给 Claude 按口径归因。
- **额外价值**：自动查出英语 7 页中文回退等线（手工漏查的样式硬伤）。

## 已知局限
- 视觉渲染（pptx→PDF→PNG）依赖 macOS + PowerPoint + PyObjC(Quartz)（与 ppt-script-fix 同）；
  缺这些时 run_audit 自动跳过视觉、仅出结构/样式诊断（不阻断）。Pillow 拼图逻辑已用合成 PNG 验证。
- docx dump 有两种格式（dump_pptx 的 `P{i} <style>` 与古诗 extractor 的 `[P|style]`），_common 已兼容。
- 页面绑定/角色分类是模糊启发式，低相似度/未归类项**必须看并排截图人工复核**（脚本已 warn）。
