# 结构检查规则说明

来自《课件生成需求汇总.md》，每条规则对应 `structural_checks.py` 中的一个检查函数。

## WPS 兼容性

| 规则 | 检查方式 | 失败含义 |
|---|---|---|
| 无 bare m:limUpp | XML 查找 m:limUpp 且无 m:e 子节点 | WPS 打开时会卡死/崩溃 |
| oMath 无 U+200B | XML 查找 m:t 节点含零宽空格 | 公式渲染错误 |

## 字体

| 规则 | 检查方式 | 失败含义 |
|---|---|---|
| ea typeface = 微软雅黑 | XML 查找 a:ea typeface 非微软雅黑 | 中文显示为等线（模板主题默认）|

*注：模板 Hans 脚本字体映射为等线，lang="zh-CN" 不够，必须显式设 a:ea*

## 行距

| 规则 | 检查方式 | 含义 |
|---|---|---|
| 标准行距 | spcPct 值为 140000 或 120000 | 1.4× 正常 / 1.2× 溢出缩小后 |

## 正课页面顺序（里程碑检查）

按以下顺序在版式名中出现：
1. 你知道吗
2. 标题（含"标题"且不含"模块"）
3. 探索任务
4. 本讲巩固标题
5. 再见/拜拜

## 小班课页面顺序

1. 标题页
2. 榜上有名
3. 知识回顾
4. 本讲巩固标题
5. 再见/拜拜

## 章节特殊规则

| 章节 | 规则 | 检查方式 |
|---|---|---|
| 学习指南 | 页面为空，无表格 | XML 无 a:tbl 节点 |
| 你知道吗 | 后面紧跟目录页版式 | 查找后续3页内含"目录"的版式名 |
| 新知速递/真题速递 | 最后一个后跟同版式空白页 | 检查最后出现位置的下一页版式名 |

## 新增规则方式

在 `structural_checks.py` 中添加新函数，并在 `run_all_checks()` 中调用：

```python
def check_my_new_rule(prs, label):
    results = []
    # ... 检查逻辑 ...
    if not any(r[1] == "FAIL" for r in results):
        results.append(("新规则名", "PASS", f"[{label}] 通过"))
    return results
```
