## 写报告时的纪律
- **先 Read 完所有证据再写**（三份 JSON + 缩略网格 + 全部并排图）。
- 每个判定挂**证据指针**，可追溯。
- 区分「事实」（脚本给）与「判断」（你给）：A/B/C、根因、补丁都是你的判断，要能自圆其说。
- 不确定 A 还是 B 的（尤其边界1的口径问题）→ 在报告里**显式标注「待用户拍板」**，给默认值，别硬判。
